# 摘要反模式清单（lint 规则来源）

每条给出：在 39 篇优秀论文摘要语料中的实测计数（`abstract_corpus_stats.md`），在自动生成摘要中的典型表现，对应 lint 规则。
加规则前先在语料上数一遍：优秀论文里常见的写法不算反模式。

## 1. 数字堆叠（A02 / A03 / A04）

- 语料：数字 P50 = 15、P75 = 24、max = 52；≥ 4 位有效数字 P50 = 0、P75 = 5；单句最多数字 P50 = 4、P75 = 6。
- 自动稿：90+ 个数字、10+ 个四位小数、单句 7–10 个数字、`5 / 4 / 4 / 3` 式并列（语料 0 例）。
- 根因：把正文"结果汇报"段直接搬进摘要，每个口径、每个类别、每个中间量都写。
- 改法：每问 ≤ 4 个数字；只留最终口径；四位小数写约数；并列改成定性覆盖或只留极值。

## 2. 过程参数与规格数字（A02，`select_facts.py` 降权）

- 优秀摘要极少写超参数、窗长、步长、采样率、时长、通道数；写的是"用什么方法、比什么好、好多少"。
- 自动稿常见：`max_depth=10`、`1.0 s 窗、0.5 s 步长`、`32 kHz、8 s`、`$N_d=20$、$d/D=0.135$`。
- 改法：参数退回正文；若参数本身是结论（"窗长对判决不敏感"）用文字说。

## 3. 标题句式的问题分段（A12）

- 语料：31–35/39 篇用"针对问题 N，…"作段首，直接接方法；没有一篇用 `**问题一（xxx）。**` 式加粗小标题。
- 改法：段首"针对问题一，"，第一句就写这一问的矛盾或方法。

## 4. 内部名与依赖正文上下文的引用（A09 / A16 / A17）

- 语料：0 例 `.mat` / `reports/` / `图 3` / `表 2` / `$…$` / `@fig:`。
- 自动稿：`.mat 文件`、`题目表 2`、`见图`、`$P(\\mathrm N)$`、`$\\log$ 峰值`。
- 改法：摘要必须自足；公式符号改文字（"正常后验"），题面表格改文字（"题目给出的特征频率公式"）。
- 例外：`题目 / 题面 / 附件 + 表 N` 是引用题目而非正文，只 WARN。

## 5. 限定词丢失（V02）

- 正文说"探索性假设""不能解读为准确率""低置信""无标签 / 无真值"，摘要压缩时最容易被删掉，从而把推断写成事实。
- `verify_abstract.py`：正文中每次出现都带强限定词的数字，摘要句里必须也带（FAIL）；正文中多数时候被强限定的加粗术语，摘要句为确定语气时 WARN。
- 强限定词表见 `abstract_common.STRONG_HEDGE`。

## 6. 关键词过多 / 过碎（A06）

- 语料：关键词 P50 = 5、P75 = 7、max = 15。
- 自动稿：10 个，含"SHAP""自训练"等三级方法名。
- 改法：领域 1 + 核心方法 2–3 + 特色 1，共 3–6 个；关键词必须在正文出现（V03）。

## 7. 缺结尾（A07）

- 语料：59% 的摘要在最后一段写创新 / 优缺点 / 推广（"创新"一词出现 63 次 / 39 篇）。
- 自动稿：结尾是"本文所有数值均可一键复现"或什么都没有。
- 改法：至少一句"本文的特点是…"，一句局限（诚实）；有推广就加一句。

## 8. AI 风格套话（A08）

- 语料：`极具` 2 次，其余 0（`赋能、全方位、有力支撑、多维度、值得一提的是、闭环、一站式、深远影响…`）。
- 词表见 `abstract_common.AI_PHRASES`；命中即 WARN。

## 9. 空转动词（A18）

- "进行了 X 的研究 / 开展了 X 工作 / 实现了对 X 的分析"：语料里偶见但不成风；自动稿密集出现。
- 改法：直接写 X。

## 10. 开头过长（A12）

- 语料：第一个"问题 N"之前 P50 = 156 字、P75 = 243 字（一个 844 字的离群值是把整段研究背景写进了摘要）。
- 改法：背景 2 句 + 任务 1 句 + 总体方案 1 句。

## 11. 数字漂移（V01）

- 摘要写的数字在正文 / 报告里找不到：多为手改四舍五入不一致（0.9375 写成 0.93）、抄错口径、或直接编造。
- `verify_abstract.py` 精确匹配 `number_pool`；带"约 / 近 / 超过 / 不到"等约数词且 ≤ 3 位有效数字时允许四舍五入匹配（误差 ≤ 6%）。
