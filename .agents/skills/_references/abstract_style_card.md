# 摘要风格卡（abstract-write 的唯一依据）

来源：39 篇 2023 年研究生数模竞赛优秀论文（C/D/E/F 各约 10 篇）摘要的实测分布（`abstract_corpus_stats.md`），
以及与 draft / polish 阶段自动生成摘要的对照。阈值一律是"语料 P75"，超过语料最大值才算硬 FAIL；样本增加后重新统计。

## 1. 一句话原则

> 摘要是评委读的第一页，也可能是唯一认真读的一页：让评委在 1000 字里看懂"题目难在哪 → 每一问用什么方法解决 → 得到什么可核验的结论 → 结论可靠到什么程度"。
> 数字只留下**能证明结论**的那几个，其余全部退回正文。

## 2. 硬指标（`lint_abstract.py` 强制；> P75 WARN，> 语料最大值 FAIL）

| 指标 | 语料 P25 / P50 / P75 | 语料最大 | 典型 draft 摘要 | 怎么改 |
| --- | ---: | ---: | ---: | --- |
| 汉字数 | 911 / 1137 / 1377 | 1697 | 1700+ | 每问一段 ≤ 300 字；过程参数、中间统计量退回正文 |
| 数字个数 | 4 / 15 / 24 | 52 | 90+ | 每问 ≤ 4 个数字，只留最终指标、关键对比、覆盖规模 |
| 数字 / 千汉字 | 3.1 / 12.5 / 22.1 | 39.2 | 50+ | 同上 |
| ≥ 4 位有效数字 | 0 / 0 / 5 | 14 | 10+ | 0.9431 → "约 0.94"；参数估计区间 9.530–9.715 → 不进摘要 |
| 单句最多数字 | 2 / 4 / 6 | 18 | 7–10 | 一句最多 3 个数字；`a / b / c` 式并列一律拆掉或只留最关键的一个 |
| 句长中位数（汉字） | 42 / 50 / 57 | 151 | 60–80 | 一句只说一件事；"先…再…最后…"拆成 2–3 句 |
| 开头段汉字 | 123 / 156 / 243 | 844 | 200–300 | 背景 2 句 + 任务 1 句 + 总体方案 1 句 |
| 关键词数 | 4 / 5 / 7 | 15 | 10 | 3–6 个：领域 + 核心方法 2–3 个 + 特色 1 个 |

## 3. 结构模板（语料 31–35/39 篇用"针对问题 N"分段）

```text
段 0  背景与总体方案（120–240 字，≤ 2 个数字）
      · 题目背景 1–2 句（为什么难：数据稀缺 / 跨域 / 多目标冲突…）
      · 本文做了什么 1 句：以 X 为主线，建立 A → B → C 的技术链路
段 1..n  针对问题 N（180–300 字，≤ 4 个数字）
      · 输入 / 矛盾：这一问要解决什么、有什么困难（1 句）
      · 方法与改进点：用什么模型、比标准做法多做了什么（2–3 句）
      · 可核验结果：1–3 个最终指标或判决（1–2 句，数字带"约"时 ≤ 3 位有效数字）
      · 验证动作 / 向下一问交接（1 句）
段 n+1  模型检验（可选，60–120 字）：扰动维度、一致率、最敏感因素
段 n+2  结尾（80–150 字，0 个数字）
      · 特点 / 创新 1–2 句（用"本文的特点是…"，不要"创新点如下：1. 2. 3."）
      · 局限 1 句（诚实，含"探索性假设 / 无真值 / 低置信"等正文原有限定）
      · 推广 1 句（可选）
关键词：3–6 个，分号分隔
```

## 4. 数字取舍规则（`select_facts.py` 评分依据）

**留**：最终模型的核心指标（宏 F1、RMSE、一致率…）；决定结论的关键对比（"随机划分会使指标虚高到 0.99"）；覆盖规模（N 个文件、M 个扰动设置）；分数式结果（12/16）。

**不留**：
- 过程参数（树深度、窗长、步长、网格搜索得到的几何 / 超参数）；
- 中间统计量（各类样本数、域差指标从 a → b → c 的整条链）；
- 与结论无关的规格数字（采样率、时长、通道数），除非它本身是难点（"跨采样率"用文字说即可）；
- 同一指标的多种口径（段级 + 文件级 + 留出集 + 交叉验证）——只留一个口径，其余退回正文；
- ≥ 4 位有效数字的原值——写"约 0.94 / 近 0.95 / 超过 0.9"，`verify_abstract.py` 按约数匹配。

**改写模板**（数字为示意）：

| 坏 | 好 |
| --- | --- |
| 段级准确率 0.9431、宏 F1 0.9527、宏 AUC 0.9950，文件级准确率 0.9400、宏 F1 0.9507 | 留出集文件级宏 F1 约 0.95 |
| 四类样本数依次为 5 / 4 / 4 / 3 | 四类均出现 |
| 三种对照方法的一致率仅 0.250 / 0.438 / 0.188 | 三种对照方法的一致率不超过 0.44 |
| 参数估计落在 9.530–9.715，其中 8 个…其余回退到 9.55 | 提出 XX 精修方法，使该参数在目标数据上可估计 |
| 三个系数分别为 −5.068、−3.352、−2.160，均为负 | 系数方向与机理预期一致 |

## 5. 句法与措辞

- 分段用"针对问题一，…"（语料主流），每问一段，不加粗小标题、不用"问题一（xxx）。"式标题句。
- 结果句用"结果表明 / 最终 / 得到"引出，一个结果一句。
- 方法句写"做了什么"，不写"进行了 X 的研究"、"开展了 X 工作"（空转词，A18）。
- 限定词照抄正文：正文说"探索性假设"，摘要不能写成"确定"；正文说"一致率不能解读为准确率"，摘要要保留这一句或等价表述。
- 不出现 `.mat`、`reports/`、`results/`、图表编号、章节号、公式标签、`$…$` 行内公式（评委看的是 Word 摘要页，不是 Markdown）。
- 摘要必须自足：删掉"见图 3"、"如表 2 所示"、"本章"、"上一节"。

## 6. 允许 / 禁止

允许：约数（约、近、超过、不到）；分数式（12/16）；"四类均出现"式的定性覆盖描述；在结尾诚实写出局限。

禁止：新增正文没有的数字或结论；把目标域预测标签写成真实标签；把"与机理判据一致率 0.75"写成"准确率 75%"；删掉正文原有的"无标签 / 无真值 / 低置信 / 待复核"限定。
