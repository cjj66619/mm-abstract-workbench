# abstract-write

## 开写前读三样

1. `abstract/ABSTRACT_PLAN.md`：预算表 + 每问候选数字（含 `must_hedge`、`round_hint`）+ 结论句 + 关键词候选。
2. `.agents/skills/_references/abstract_style_card.md`：硬指标、结构模板、数字取舍、改写模板。
3. `abstract/ABSTRACT_LINT_BEFORE.md`（若有）：旧摘要哪里超标，避免重犯。

正文本身只在需要核对某句原意时打开；不要边读正文边写，那会把正文的数字全搬进来。

## 写法

```text
段 0   背景 1–2 句 → 任务 1 句 → 总体方案 1 句。≤ 2 个数字，120–240 字。
段 N   "针对问题 N，" + 矛盾 1 句 + 方法与改进点 2–3 句 + 结果 1–2 句 + 验证/交接 1 句。≤ 4 个数字，180–300 字。
检验段 （有 robustness / evaluation 章时）扰动维度、一致率、最敏感因素。≤ 3 个数字。
结尾   "本文的特点是…" 1–2 句 + 局限 1 句 + 推广 1 句（可选）。0 个数字。
关键词：A；B；C；D（3–6 个，全部在正文出现过）
```

文件格式：可选一行 `# 摘要` 标题；正文纯段落，段间空行；最后一行 `关键词：…`。不用加粗、列表、`$…$`、脚注。

## 数字：每写一个问三句话

1. 它证明的结论是什么？答不上来 → 删。
2. 同一结论已有数字了吗？有 → 删（一个结论一个数字，一个口径）。
3. 它 ≥ 4 位有效数字吗？是 → 写 `round_hint` 的约数（"约 0.95"），除非是题目要求精确汇报的量。

计划里没有的数字一个都不写。要用计划外的数字，先回正文确认原句，再把 `line` 记到 `ABSTRACT_REWRITE_LOG.md`。

## 限定词：只能加不能减

正文说"探索性假设 / 初步 / 低置信 / 待复核 / 无标签 / 无真值 / 合成数据 / 不能解读为…"，摘要句里必须有同义限定。
典型改法：

| 正文 | 摘要 |
| --- | --- |
| 与机理判据的一致率为 12/16 = 0.75；由于目标域无真值，该一致率不能解读为准确率 | 与独立机理判据一致 12/16；目标域无真值，该一致率不是准确率 |
| 等效参数取值为探索性假设，不构成型号判断 | 等效参数为探索性假设，仅用于… |

## 常见删法（对应 lint 规则）

- `A / B / C / D` 数字并列 → 写"四类均出现"或只留极值（A04）。
- 同一指标段级 + 文件级 + 交叉验证三口径 → 留一个（A02）。
- 参数、窗长、采样率、树深度 → 删（A02）。
- `**问题一（xxx）。**` 小标题 → "针对问题一，"（A12 / A16）。
- `见图 3 / 表 2 / 第 4 章 / reports/` → 删或改成文字（A09 / A17）。
- "进行了 X 的研究" → 直接写 X（A18）。
- "赋能 / 全方位 / 值得一提的是 / 闭环" → 删（A08）。
