# 四、符号说明

本文主要符号如 @tbl:symbols 所示，其余符号在首次出现处定义。

Table: 主要符号说明 {#tbl:symbols}

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| $t$ | 给药后时间 | h |
| $C(t)$ | 血药浓度 | mg/L |
| $D$ | 单次给药剂量 | mg |
| $k_a$ | 一级吸收速率常数 | 1/h |
| $k_e$ | 一级消除速率常数 | 1/h |
| $A$ | 幅值参数，$A=FDk_a/[V(k_a-k_e)]$ | mg/L |
| $t_{1/2}$ | 消除半衰期，$\ln 2/k_e$ | h |
| $T_{\max}$, $C_{\max}$ | 单剂量达峰时间与峰浓度 | h, mg/L |
| $AUC$ | 单剂量浓度–时间曲线下面积 | mg·h/L |
| $\tau$ | 给药间隔 | h |
| $C_{ss,\max}$, $C_{ss,\min}$ | 稳态峰浓度、稳态谷浓度 | mg/L |
| $C_{ss,avg}$ | 稳态平均浓度，$AUC/\tau$ | mg/L |
| $PTF$ | 峰谷波动，$(C_{ss,\max}-C_{ss,\min})/C_{ss,avg}$ | — |
| $R_{ac}$ | 蓄积比，$1/(1-e^{-k_e\tau})$ | — |
| $t_{90}$ | 达到 90% 稳态所需时间，$\ln 10/k_e$ | h |
| $[L,U]$ | 治疗窗，本文取 $[3,12]$ | mg/L |
